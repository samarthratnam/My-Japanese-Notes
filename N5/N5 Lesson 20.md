# SECTION 2: 📝 GRAMMAR

## 1. Polite Style vs Plain Style（～ます / ～です → Plain Form）

**Meaning / Use:**  
Polite style is used with people you are not close to. Plain style is used in casual situations.

**Structure:**

```
Verb:        ～ます → plain verb
い-adj:      ～いです → ～い
な-adj:      ～です → ～だ
Noun:        ～です → ～だ
```

**Explanation:**

- Polite style commonly uses **～ます** and **～です**.
- Plain style uses basic/plain forms.
- Use polite style with teachers, superiors, strangers, and first meetings.
- Plain style can be used with close friends and family.
- If unsure, polite style is safer.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|明日東京へ行きます。|Ashita Toukyou e ikimasu.|I will go to Tokyo tomorrow.|
|明日東京へ行く。|Ashita Toukyou e iku.|I will go to Tokyo tomorrow.|
|毎日忙しいです。|Mainichi isogashii desu.|I am busy every day.|
|毎日忙しい。|Mainichi isogashii.|I am busy every day.|
|相撲が好きです。|Sumou ga suki desu.|I like sumo.|
|相撲が好きだ。|Sumou ga suki da.|I like sumo.|

---

## 2. Plain Form of い-Adjectives（～いです → ～い）

**Meaning / Use:**  
An い-adjective normally becomes plain by removing **です**.

**Structure:**

```
い-adjective + です → い-adjective
```

**Explanation:**

- Keep the adjective itself.
- Remove **です**.
- Example: **忙しいです → 忙しい**.
- Example: **安いです → 安い**.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|毎日忙しい。|Mainichi isogashii.|I am busy every day.|
|安い。|Yasui.|It is cheap.|
|おいしい。|Oishii.|It is tasty.|
|からい。|Karai.|It is spicy.|

**Common mistakes:**  
Do not add **だ** after an い-adjective: **忙しいだ** ❌.

---

## 3. Plain Form of な-Adjectives（～です → ～だ）

**Meaning / Use:**  
A な-adjective uses **だ** in a plain statement.

**Structure:**

```
な-adjective + です → な-adjective + だ
```

**Explanation:**

- **です → だ** in a plain statement.
- Example: **好きです → 好きだ**.
- Example: **元気です → 元気だ**.
- In casual questions, **だ** is normally omitted.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|相撲が好きだ。|Sumou ga suki da.|I like sumo.|
|元気だ。|Genki da.|I am well.|
|暇だ。|Hima da.|I am free.|
|暇じゃない。|Hima janai.|I am not free.|

---

## 4. Plain Form of Nouns（Noun + です → Noun + だ）

**Meaning / Use:**  
A noun uses **だ** in a plain statement.

**Structure:**

```
Noun + です → Noun + だ
```

**Explanation:**

- **です → だ** in a plain statement.
- Example: **先生です → 先生だ**.
- Example: **学生です → 学生だ**.
- In casual questions, **だ** is normally omitted.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|先生だ。|Sensei da.|I am a teacher.|
|学生だ。|Gakusei da.|I am a student.|
|学生？|Gakusei?|Are you a student?|
|暇？|Hima?|Are you free?|

---

## 5. たい-Form（～たい）

**Meaning / Use:**  
Used to say that you **want to do** something.

**Structure:**

```
Verb stem + たい
```

**Explanation:**

- **～たいです** is polite.
- **～たい** is plain.
- Example: **登りたいです → 登りたい**.
- Example: **行きたいです → 行きたい**.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|富士山に登りたいです。|Fujisan ni noboritai desu.|I want to climb Mt. Fuji.|
|富士山に登りたい。|Fujisan ni noboritai.|I want to climb Mt. Fuji.|
|行きたいです。|Ikitai desu.|I want to go.|
|行きたい。|Ikitai.|I want to go.|

---

## 6. Past Experience（～たことがありません → ～たことがない）

**Meaning / Use:**  
Used to say that you **have never done something**.

**Structure:**

```
Verb past form + ことがありません
→ Verb past form + ことがない
```

**Explanation:**

- **～たことがありません** is polite.
- **～たことがない** is plain.
- **こと** expresses the experience.
- The plain negative changes **ありません → ない**.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|ドイツへ行ったことがありません。|Doitsu e itta koto ga arimasen.|I have never been to Germany.|
|ドイツへ行ったことがない。|Doitsu e itta koto ga nai.|I have never been to Germany.|
|行ったことがない。|Itta koto ga nai.|I have never been.|
|行ったことがありません。|Itta koto ga arimasen.|I have never been.|

---

## 7. Plain Style in Conversation（～か → no か）

**Meaning / Use:**  
In casual questions, **か** is often dropped.

**Structure:**

```
Polite:  Verb + ます + か
Plain:   Verb + plain form + ?
```

**Explanation:**

- **か** is often omitted in casual conversation.
- The voice usually rises at the end.
- Example: **飲みますか？ → 飲む？**
- The question remains understandable from the context.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|コーヒーを飲みますか？|Koohii o nomimasu ka?|Do you want coffee?|
|コーヒーを飲む？|Koohii o nomu?|Do you want coffee?|
|ご飯を食べる？|Gohan o taberu?|Will you eat a meal?|
|明日京都へ行かない？|Ashita Kyouto e ikanai?|Won't you go to Kyoto tomorrow?|

---

## 8. Casual Questions with Nouns / な-Adjectives（～？）

**Meaning / Use:**  
In casual questions with nouns and な-adjectives, **だ** is normally omitted.

**Structure:**

```
Noun + ?
な-adjective + ?
```

**Explanation:**

- A plain statement uses **だ**.
- A casual question normally drops **だ**.
- **暇だ。 → 暇？**
- **学生だ。 → 学生？**

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|今晩暇？|Konban hima?|Are you free tonight?|
|暇？|Hima?|Are you free?|
|学生？|Gakusei?|Are you a student?|
|暇だ？ ❌ → 暇？|Hima?|Are you free?|

**Common mistakes:**  
**暇だ？** is normally not used for this casual question pattern. Use **暇？**.

---

## 9. Casual Answers（～だ / ～じゃない）

**Meaning / Use:**  
Used for informal positive and negative answers.

**Structure:**

```
Positive: N / な-adjective + だ
Negative: N / な-adjective + じゃない
```

**Explanation:**

- **だ** is used in a plain positive statement.
- **じゃない** is used for a plain negative.
- In casual speech, **うん** can mean yes.
- **ううん** can mean no.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|うん、暇だ。|Un, hima da.|Yes, I am.|
|うん、暇。|Un, hima.|Yes, I am.|
|ううん、暇じゃない。|Uun, hima janai.|No, I'm not free.|
|うん、元気だ。|Un, genki da.|Yes, I am well.|

---

## 10. Plain Style Can Drop Particles

**Meaning / Use:**  
Some particles can be omitted in casual conversation when the meaning is obvious.

**Structure:**

```
Gohan o taberu? → Gohan taberu?
```

**Explanation:**

- **を (o)** can sometimes be omitted.
- The meaning must remain clear.
- Particles such as **で, に, から, まで, と** are generally not dropped when removing them would make the sentence unclear.
- Context is important.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|ご飯を食べる？|Gohan o taberu?|Will you eat a meal?|
|ご飯食べる？|Gohan taberu?|Will you eat?|
|明日京都へ行かない？|Ashita Kyouto e ikanai?|Won't you go to Kyoto tomorrow?|
|相撲のチケットがあるけど、一緒に行かない？|Sumou no chiketto ga aru kedo, issho ni ikanai?|I have sumo tickets. Won't you come with me?|

## 11. ～ている → ～てる

**Meaning / Use:**  
In casual speech, **～ている** can become **～てる**.

**Structure:**

```
～ている → ～てる
```

**Explanation:**

- This is common in casual speech.
- **持っている → 持ってる**.
- **持っていない → 持ってない**.
- The meaning stays the same.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|辞書、持っている？|Jisho, motte iru?|Do you have a dictionary?|
|辞書、持ってる？|Jisho, motteru?|Do you have a dictionary?|
|うん、持っている。|Un, motte iru.|Yes, I do.|
|うん、持ってる。|Un, motteru.|Yes, I do.|
|ううん、持っていない。|Uun, motte inai.|No, I don't.|
|ううん、持ってない。|Uun, mottenai.|No, I don't.|

**Common mistakes:**  
The casual form is **～てる**, not **～ている** when specifically making this contraction.

## 12. けど（けど）

**Meaning / Use:**  
**けど** connects two ideas and means **but / though**.

**Structure:**

```
A + けど + B
A, but B.
```

**Explanation:**

- **けど** connects two ideas.
- It works similarly to **が**.
- It is common in casual conversation.
- The basic meaning is **but / though**.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|うん、からいけど、おいしい。|Un, karai kedo, oishii.|Yes, it's spicy, but it's tasty.|
|相撲のチケットがあるけど、一緒に行かない？|Sumou no chiketto ga aru kedo, issho ni ikanai?|I have sumo tickets. Won't you come with me?|
|からいけど、おいしい。|Karai kedo, oishii.|It's spicy, but tasty.|
|いいね。|Ii ne.|Sure / Sounds good.|

## 13. Polite vs Plain by Situation

**Meaning / Use:**  
The style changes depending on who you are talking to and the situation.

**Structure:**

```
Not close / unsure → Polite
Close friends / family → Plain
```

**Explanation:**

- Teacher → polite.
- Boss / superior → polite.
- Stranger → polite.
- First meeting → polite.
- Close friend → plain.
- Family → plain.
- Diaries, books, and newspapers → plain.
- If unsure, polite style is safer.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|コーヒーを飲みますか？|Koohii o nomimasu ka?|Do you want coffee?|
|コーヒーを飲む？|Koohii o nomu?|Do you want coffee?|
|暇ですか？|Hima desu ka?|Are you free?|
|暇？|Hima?|Are you free?|

## 14. Informal Yes / No（うん / ううん）

**Meaning / Use:**  
Used for informal **yes** and **no**.

**Structure:**

```
はい → うん
いいえ → ううん
```

**Explanation:**

- **はい** = polite yes.
- **うん** = informal yes.
- **いいえ** = polite no.
- **ううん** = informal no.

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|うん。|Un.|Yes.|
|ううん。|Uun.|No.|
|うん、暇だ。|Un, hima da.|Yes, I am.|
|ううん、暇じゃない。|Uun, hima janai.|No, I'm not free.|
