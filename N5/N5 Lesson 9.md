# Grammar

---

# I. N があります (To Have)
[N + ga + arimasu]

Used to say you have something.

Pattern
```
N があります
```

---

Examples

```
Kuruma ga arimasu.

I have a car.
```

```
Youji ga arimasu.

I have something to do.
```

Question

```
Youji ga arimasu ka?

Do you have something to do?
```

Answers

```
Hai, arimasu.

Yes, I do.
```

```
Iie, arimasen.

No, I don't.
```

---

Extra Examples

```
Jikan ga arimasu.

I have time.
```

```
Okane ga arimasu.

I have money.
```

```
Kippu ga arimasu.

I have a ticket.
```

---

## Note

**Arimasu** is only used for **things or non-living objects**.

For people or animals, use

```
Imasu
```

Example

```
Tomodachi ga imasu.

I have a friend.
```

---

# II. N が分かります (Understand)

Pattern

```
N が分かります
```

Examples

```
Nihongo ga wakarimasu.

I understand Japanese.
```

```
Kanji ga wakarimasu.

I understand Kanji.
```

Question

```
Nihongo ga wakarimasu ka?

Do you understand Japanese?
```

Answer

```
Hai, wakarimasu.

Yes.
```

```
Iie, wakarimasen.

No.
```

---

Extra Examples

```
Eigo ga wakarimasu.

I understand English.
```

```
Sensei no hanashi ga wakarimasu.

I understand the teacher's explanation.
```

---

# III. N が好きです (Like)

**Suki is NOT a verb.**

It is a **na-adjective.**

Pattern

```
N が好きです
```

Examples

```
Kare wa supootsu ga suki desu.

He likes sports.
```

```
Kanojo wa dansu ga suki desu.

She likes dancing.
```

Question

```
Supootsu ga suki desu ka?

Do you like sports?
```

Answer

```
Hai, suki desu.

Yes.
```

---

Extra Examples

```
Watashi wa ongaku ga suki desu.

I like music.
```

```
Watashi wa sushi ga suki desu.

I like sushi.
```

---

# IV. N が嫌いです (Dislike)

Pattern

```
N が kirai desu
```

Examples

```
Sono eiga ga kirai desu.

I don't like that movie.
```

```
Yasai ga kirai desu.

I dislike vegetables.
```

Question

```
Yasai ga kirai desu ka?

Do you dislike vegetables?
```

---

**Correction**

In everyday Japanese, saying **kirai** directly can sound strong.

Instead many people politely say

```
Amari suki ja arimasen.

I don't like it very much.
```

---

Pattern


Examples


```
Kanojo wa dansu ga jouzu desu.

```

Question

```
Supootsu ga jouzu desu ka?

```

---

Extra Examples

```

```


---

# VI. N が下手です (Bad At)

Pattern

```

```

Examples

```

```

```

```

---

Extra Examples

```

```

```
Supootsu ga heta desu.

```

---

## Study Tip

**Jouzu** and **Heta** are adjectives.

They are **not verbs.**

# VIII. Quantity Words

## Positive

### Yoku

Very well

```
Nihongo ga yoku wakarimasu.

I understand Japanese very well.
```

---

### Daitai

Mostly

```
Nihongo ga daitai wakarimasu.

I understand most Japanese.
```

---

### Sukoshi

A little

```
Nihongo ga sukoshi wakarimasu.

I understand a little Japanese.
```

---

## Negative

### Amari

Not very

Must be used with a negative verb.

```
Nihongo ga amari wakarimasen.

I don't understand Japanese very well.
```

---

### Zenzen

Not at all

Always with a negative.

```
Nihongo ga zenzen wakarimasen.

I don't understand Japanese at all.
```

---

## The same words with Arimasu

Positive

```
Takusan arimasu.

I have many.
```

```
Sukoshi arimasu.

I have a little.
```

Negative

```
Amari arimasen.

I don't have much.
```

```
Zenzen arimasen.

I don't have any at all.
```

Examples

```
Okane ga takusan arimasu.

I have lots of money.
```

```
Okane ga sukoshi arimasu.

I have a little money.
```

```
Okane ga amari arimasen.

I don't have much money.
```

```
Okane ga zenzen arimasen.

I have no money at all.
```

---

## Note

These adverbs also work with adjectives.

```
Totemo atsui desu.

Very hot.
```

```
Sukoshi samui desu.

A little cold.
```

```
Amari atsuku nai desu.

Not very hot.
```

```
Zenzen samuku nai desu.

Not cold at all.
```

# IX. Because (から)

Pattern 1

```
S1 kara, S2.
```

Because S1, S2.

Pattern 2

```
S2.

S1 kara.
```

S2 because S1.

Examples

```
Jikan ga amari arimasen.

Kara benkyou shimasen.

I don't have much time, so I won't study.
```

Or

```
Benkyou shimasen.

Jikan ga amari arimasen kara.

I won't study because I don't have much time.
```

More Examples

```
Ame desu kara ikimasen.

Because it's raining, I won't go.
```

```
Isogashii desu kara kaerimasu.

Because I'm busy, I'm going home.
```

---

# X. Asking Why

Question

```
Doushite desu ka?

Why?
```

Or

```
Doushite benkyou shimasen deshita ka?

Why didn't you study?
```

Answer

```
Jikan ga arimasen kara.

Because I didn't have time.
```

---

Another Example

```
Kyou hayaku kaerimasu.

I'm going home early today.
```

Question

```
Doushite desu ka?

Why?
```

Answer

```
Youji ga arimasu kara.

Because I have something to do.
```

---

# Important Notes ⭐

- **Suki (好き), Kirai (嫌い), Jouzu (上手), and Heta (下手)** are **na-adjectives**, not verbs.
- **Wakarimasu** takes **が (ga)**, not **を (o)**.
- **Arimasu** is used only for non-living things; use **Imasu** for people and animals.
- **Amari** and **Zenzen** should be followed by a **negative** form.
- **Kara** means **because**, and it can appear either at the end of the reason clause (_Ame desu kara..._) or after the reason when giving an explanation.
