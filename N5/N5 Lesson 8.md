# Introduction – Japanese Adjectives

Unlike English, Japanese adjectives are divided into **two categories**.

## 1. い-Adjectives (I-Adjectives)

These adjectives usually end with **い (i)**.

Examples:

- Atsui (暑い) – hot
- Samui (寒い) – cold
- Oishii (美味しい) – delicious
- Takai (高い) – expensive/high
- Yasui (安い) – cheap
- Omoshiroi (面白い) – interesting

### Rule

When directly describing a noun,

Simply place the adjective before the noun.

Example

```
Takai kuruma
Expensive car

Oishii tabemono
Delicious food
```

No particle is needed.

---

## 2. な-Adjectives (Na-Adjectives)

These do NOT end with the grammatical い (although some words like **Kirei** end with an "i" sound).

When describing a noun, add **な (na).**

Examples

- Hansamu (ハンサム) – handsome
- Kirei (きれい) – beautiful/clean
- Genki (元気) – healthy
- Shizuka (静か) – quiet
- Yūmei (有名) – famous
- Benri (便利) – convenient

Examples

```
Kirei na hana
Beautiful flower

Shizuka na machi
Quiet town
```

---

# IMPORTANT

Many beginners make this mistake.

These are **Na-adjectives**, even though they end with an "i" sound.

✔ Kirei

✔ Genki

✔ Yūmei

✔ Benri

✔ Hansamu

---

# Easy Trick

Ask yourself:

Can I say **"...na noun"**?

```
Kirei na hito ✔

Takai na kuruma ❌
```

If "na" is required → Na adjective.

If not → I adjective.

# Grammar

---

# I. Using Adjectives as Predicate

Pattern

## Na-Adjective

```
N wa Na-adjective desu.
```

Example

```
Kare wa hansamu desu.

He is handsome.
```

```
Kanojo wa kirei desu.

She is beautiful.
```

---

## I-Adjective

```
N wa I-adjective desu.
```

Example

```
Fuji-san wa takai desu.

Mt. Fuji is tall.
```

```
Osaka wa nigiyaka desu.

Osaka is lively.
```

---

# II. Negative Form of Adjectives

---

## Na-Adjective

Pattern

```
N wa Na-adjective ja arimasen.
```

Example

```
Kare wa hansamu ja arimasen.

He isn't handsome.
```

---

## I-Adjective

Remove final い

Add

```
kunai desu
```

Example

```
Omoshiroi

↓

Omoshiroku nai desu
```

Movie isn't interesting.

```
Eiga wa omoshiroku nai desu.
```

---

Another example

```
Kuruma wa takaku nai desu.

The car isn't expensive.
```

---

# III. Adjective Before Noun

---

## Na-Adjective

```
Na-adjective + na + noun
```

Example

```
Nigiyaka na machi

Lively city
```

```
Kirei na hana

Beautiful flower
```

---

## I-Adjective

```
I-adjective + noun
```

Example

```
Oishii tabemono

Delicious food
```

```
Takai kuruma

Expensive car
```

---

# IV. Very / Not Very

---

## Very

```
Totemo + adjective
```

Example

```
Osaka wa totemo nigiyaka desu.

Osaka is very lively.
```

```
Kono hon wa totemo omoshiroi desu.

This book is very interesting.
```

---

## Not Very

Na-adjective

```
Amari + adjective + ja arimasen
```

Example

```
Kare wa amari genki ja arimasen.

He isn't very healthy.
```

---

I-adjective

```
Amari + adjective(kunai)
```

Example

```
Kono eiga wa amari omoshiroku nai desu.

This movie isn't very interesting.
```

---

# V. Asking "How is...?"

Pattern

```
N wa dou desu ka?
```

Examples

```
Eiga wa dou desu ka?

How is the movie?
```

```
Nihon no seikatsu wa dou desu ka?

How is life in Japan?
```

```
Ryou wa dou desu ka?

How is the dormitory?
```

---

# VI. Asking "What kind of...?"

Pattern

```
N1 wa donna N2 desu ka?
```

Examples

```
Osaka wa donna machi desu ka?

What kind of city is Osaka?
```

```
Sore wa donna kaban desu ka?

What kind of bag is that?
```

Answers

```
Osaka wa nigiyaka na machi desu.

Osaka is a lively city.
```

```
Sore wa chiisai kaban desu.

That is a small bag.
```

---

# VII. Joining Sentences

---

## But

Pattern

```
Sentence 1 + ga + Sentence 2
```

Example

```
Nihon no tabemono wa oishii desu ga,
totemo takai desu.

Japanese food is delicious, but it is very expensive.
```

---

## And

Pattern

```
Sentence 1 + soshite + Sentence 2
```

Example

```
Nihon wa kirei desu.

Soshite omoshiroi desu.

Japan is beautiful, and it is interesting.
```

---

# VIII. Which One?

Pattern

```
Dore desu ka?
```

Example

```
Anata no kuruma wa dore desu ka?

Which is your car?
```

Answer

```
Ano shiroi kuruma desu.

That white car.
```

---

Another example

```
Sakura-san no uchi wa dore desu ka?

Which one is Sakura's house?

↓

Ano ookii uchi desu.

That big house.
```

# Common Mistakes (Corrections)

❌ Kirei is an **I-adjective**

✔ No. It is a **Na-adjective**.

---

❌ Genki is an I-adjective.

✔ No.

It is a Na-adjective.

---

❌ Atsui = cold

✔ Atsui = Hot (weather)

✔ Samui = Cold (weather)

✔ Tsumetai = Cold (touch)

---

❌ Ii follows normal I-adjective rules.

✔ **Ii (good)** is irregular.

Negative form:

```
Ii

↓

Yoku nai desu
```

NOT

```
Ii kunai ❌
```
