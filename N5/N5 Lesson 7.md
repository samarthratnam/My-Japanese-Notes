# Lesson 7 – Grammar

---

# I. Means / Tool

### Structure

**N (Tool / Means) + で + Verb**

Meaning

> Do something using a tool or means.

Examples

```
Hashi de tabemasu.
I eat with chopsticks.

Eigo de tegami o kakimashita.
I wrote the letter in English.

Fakkusu de repōto o okurimasu.
I will send the report by fax.
```

More Examples

```
Naifu de ringo o kirimasu.
I cut an apple with a knife.

Hasami de kami o kirimasu.
I cut paper with scissors.

Pasokon de repōto o kakimasu.
I write a report using a computer.
```

---

# II. Asking "What is ___ in Japanese?"

### Structure

**_____ wa Nihongo de nan desu ka?**

Meaning

> What is _____ in Japanese?

Examples

```
"Thank you" wa Nihongo de nan desu ka?

→ Arigatō desu.
```

More Examples

```
"Book" wa Nihongo de nan desu ka?

→ Hon desu.

"Teacher" wa Nihongo de nan desu ka?

→ Sensei desu.

"Water" wa Nihongo de nan desu ka?

→ Mizu desu.
```

---

# III. Giving Something

### Structure

**Giver は Receiver に Object を あげます**

**N(Person) は N(Person) に N(Object) を Agemasu**

Meaning

> Give something to someone.

Examples

```
Watashi wa anata ni kore o agemasu.
I will give this to you.

John-san wa Maria-san ni hana o agemashita.
John gave flowers to Maria.

Yamada-san wa watashi ni hon o agemashita.
Mr. Yamada gave me a book.
```

---

## Remember

|Role|Particle|
|---|---|
|Receiver|に|
|Object|を|

---

# IV. Receiving Something

### Structure

**Receiver は Giver に / から Object を Moraimasu**

Meaning

> Receive something from someone.

You may use **に** or **から**.

- **に** → Common with people.
- **から** → More general (people, organizations, places).

Examples

```
Maria-san wa John-san ni hana o moraimashita.
Maria received flowers from John.

Watashi wa sensei kara hon o moraimashita.
I received a book from the teacher.

Kanojo wa Yamada-san ni Nihongo o naraimashita.
She learned Japanese from Mr. Yamada.
```

---

## Difference

### Giving

```
John-san wa Maria-san ni hana o agemashita.
John gave flowers to Maria.
```

Focus = **John (giver)**

---

### Receiving

```
Maria-san wa John-san ni hana o moraimashita.
Maria received flowers from John.
```

Focus = **Maria (receiver)**

---

# V. Already

### Structure

**Mō + Verbました**

Meaning

> Already

Examples

```
Mō tabemashita.
I already ate.

Mō kaimashita.
I already bought it.

Mō yomimashita.
I already read it.
```

---

### Question

```
Mō tabemashita ka?
Did you eat already?
```

Answers

```
Hai, mō tabemashita.
Yes, I already ate.

Iie, mada desu.
No, not yet.
```

---

# VI. Borrowing

### Structure

**Borrower は Lender に / から Object を Karimasu**

Meaning

> Borrow something from someone.

Examples

```
Watashi wa Tom-san ni hon o karimashita.
I borrowed a book from Tom.

Watashi wa sensei kara pen o karimashita.
I borrowed a pen from my teacher.
```

---

# VII. Teaching / Learning

### Teaching

```
Yamada-san wa watashi ni Nihongo o oshiemasu.
Mr. Yamada teaches me Japanese.
```

### Learning

```
Watashi wa Yamada-san ni Nihongo o naraimasu.
I learn Japanese from Mr. Yamada.
```

# Corrections from Your Notes

✅ **Karimasu (借ります)** = Borrow (not "learn")

✅ **Naraimasu (習います)** = Learn

✅ **Hashi (箸)** = Chopsticks (**橋** means bridge)

✅ **Hocchikisu (ホッチキス)** = Stapler

✅ **Keshigomu (消しゴム)** = Eraser

✅ **Kami (紙)** = Paper

✅ **Shatsu (シャツ)** = Shirt

✅ **Purezento (プレゼント)** = Gift

✅ **Kippu (切符)** = Ticket

✅ **Ryokō (旅行)** = Trip / Tour

✅ **Omiyage (お土産)** = Souvenir

✅ **Yōroppa (ヨーロッパ)** = Europe

✅ **Gomen kudasai** is used when calling at someone's house or entrance, not simply "Is anyone home?"

✅ **Itadakimasu** is primarily said **before eating** to express gratitude for the meal. It can occasionally be used when politely accepting something, but that's not its main use.
