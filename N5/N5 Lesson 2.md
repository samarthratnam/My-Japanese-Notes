## Demonstrative Adjectives

|English|Romaji|Japanese|
|---|---|---|
|This ~|**Kono**|この|
|That ~ (near you)|**Sono**|その|
|That ~ (over there)|**Ano**|あの|

> **Note:**  
> Kore / Sore / Are = Pronouns (stand alone)  
> Kono / Sono / Ano = Must be followed by a noun.

Example:

- Kore wa hon desu.
- Kono hon wa omoshiroi desu.

# Lesson 2 – Grammar

---

## I. This / That / That (Over There)

### Structure

**Kore / Sore / Are wa Noun desu.**

Meaning:

- Kore = This
- Sore = That (near you)
- Are = That (over there)

Examples:

```
Kore wa hon desu.
This is a book.

Sore wa enpitsu desu.
That is a pencil.

Are wa nōto desu.
That is a notebook.
```

---

## II. This (noun) / That (noun)

### Structure

**Kono / Sono / Ano + Noun desu**

Examples

```
Kono hito wa dare desu ka?
Who is this person?

Ano hito wa dare desu ka?
Who is that person?
```

---

## III. Question

### Structure

**Sore wa ____ desu ka?**

Example

```
Sore wa techō desu ka?
Is that a diary?
```

Answers

```
Hai, sō desu.
Yes, it is.

Iie, sō ja arimasen.
No, it isn't.
```

---

## IV. Possession

### Structure

**N1 no N2**

Meaning:

> N2 belongs to N1.

Examples

```
Kamban no hon
The company's book

Watashi no hon
My book
```

More examples

```
Nihongo no hon
Japanese book

Eigo no jisho
English dictionary

Sensei no kaban
Teacher's bag
```

---

## V. Is it S1 or S2?

### Structure

**S1 ka S2 ka?**

Example

```
Sore wa terebi desu ka, rajio desu ka?
Is that a television or a radio?
```
