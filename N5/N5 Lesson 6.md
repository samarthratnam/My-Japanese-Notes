# Lesson 6 – Grammar

---

# I. Object Marker 「を (o)」

### Structure

**Noun + を + Verb**

The particle **を (wo)** is pronounced **"o"**.

Meaning:

> Marks the direct object of the verb.

Examples

```
Tabako o suimasu.
I smoke cigarettes.

Pan o tabemasu.
I eat bread.

Mizu o nomimasu.
I drink water.

Shashin o torimasu.
I take photographs.
```

More Examples

```
Hon o yomimasu.
I read a book.

Tegami o kakimasu.
I write a letter.

Eiga o mimasu.
I watch a movie.
```

---

# II. 「します (Shimasu)」

**Shimasu** means **to do**.

It is also used with many nouns to form verbs.

### Structure

**Noun + を + します**

Examples

```
Shukudai o shimasu.
I do homework.

Sukī o shimasu.
I ski.

Sakkaa o shimasu.
I play soccer.

Kaigi o shimasu.
I hold a meeting.

Benkyō o shimasu.
I study.
```

---

# III. Asking "What will you do?"

### Structure

**Nani o shimasu ka?**

Meaning

> What will you do?

Examples

```
Ashita nani o shimasu ka?
What will you do tomorrow?

Kyō nani o shimasu ka?
What will you do today?
```

Possible Answers

```
Benkyō o shimasu.
I'll study.

Eiga o mimasu.
I'll watch a movie.

Tomodachi to asobimasu.
I'll play with my friend.
```

---

# IV. "What?" (Nan / Nani)

Your notes mention:

- Before **ta, da, na** → **Nan**
- Before **a, i, u, e, o** → **Nani**

This is generally correct for pronunciation.

Examples

```
Nan desu ka?
What is it?

Nan no hon desu ka?
What book is it?

Nani o tabemasu ka?
What will you eat?

Nani o nomimasu ka?
What will you drink?
```

### Before Counters

Use **Nan-** before counters.

Examples

```
Nan-sai
How old?

Nan-nin
How many people?

Nan-pun
How many minutes?

Nan-kai
Which floor?
```

---

# V. Place + で + Action

### Structure

**Place + で + Object + Verb**

The particle **で (de)** marks the place where an action happens.

Examples

```
Mise de sake o kaimashita.
I bought Japanese wine at the shop.

Resutoran de gohan o tabemasu.
I eat at a restaurant.

Toshokan de hon o yomimasu.
I read books in the library.

Gakkō de benkyō shimasu.
I study at school.
```

---

# VI. Invitation

### Structure

**Issho ni + Verb-masen ka?**

Meaning

> Won't you...?/Would you like to...?

Examples

```
Issho ni bīru o nomimasen ka?
Won't you drink beer with me?

Issho ni eki e ikimasen ka?
Won't you go to the station with me?

Issho ni eiga o mimasen ka?
Won't you watch a movie with me?

Issho ni kōhī o nomimasen ka?
Would you like to have coffee together?
```

Typical Replies

```
Hai, ii desu ne.
Yes, sounds good.

Sumimasen, chotto...
Sorry, maybe another time.
```

---

# VII. Volitional Form (Let's...)

### Structure

**Verb (ます form) → ましょう (Mashō)**

Meaning

> Let's...

Examples

```
Ikimasu → Ikimashō
Let's go.

Tabemasu → Tabemashō
Let's eat.

Nomimasu → Nomimashō
Let's drink.

Benkyō shimasu → Benkyō shimashō
Let's study.

Kaerimasu → Kaerimashō
Let's go home.
```

Sentence Examples

```
Issho ni ikimashō.
Let's go together.

Resutoran de tabemashō.
Let's eat at the restaurant.

Kōhī o nomimashō.
Let's drink coffee.

Benkyō shimashō.
Let's study.

Shinkansen de ikimashō.
Let's go by Shinkansen.
```

# Corrections from Your Notes

- ✅ **を** is written as **を** but pronounced **"o"**.
- ✅ **Noun + を + Verb** is the standard object pattern.
- ✅ **Shimasu** means "to do" and combines with many nouns (e.g., _benkyō o shimasu_, _sukī o shimasu_).
- ✅ **Nan** and **Nani** are both "what," but **Nan** is commonly used before counters and before sounds like **d**, **t**, and **n** (e.g., _nan desu ka_, _nan-nin_, _nan-sai_), while **Nani** is typically used before particles like **を**, **が**, etc. (e.g., _nani o tabemasu ka?_).
- ✅ **で (de)** marks the place where an action occurs.
- ✅ **Issho ni ~masen ka?** is a polite invitation ("Won't you...? / Would you like to...?").
- ✅ **～ましょう (mashō)** expresses **"Let's..."** and is the polite volitional form.
