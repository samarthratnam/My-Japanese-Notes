> [!important] How to use this page  
> Don't try to memorize everything in one day.  
> **Hiragana → numbers → time → dates → counters → colors → basic question words → essential particles → basic verbs**.
>

# 1. 🔤 Hiragana

## Basic 46

|Row|あ|い|う|え|お|
|---|---|---|---|---|---|
|**Vowels**|あ a|い i|う u|え e|お o|
|**K**|か ka|き ki|く ku|け ke|こ ko|
|**S**|さ sa|し shi|す su|せ se|そ so|
|**T**|た ta|ち chi|つ tsu|て te|と to|
|**N**|な na|に ni|ぬ nu|ね ne|の no|
|**H**|は ha|ひ hi|ふ fu|へ he|ほ ho|
|**M**|ま ma|み mi|む mu|め me|も mo|
|**Y**|や ya|—|ゆ yu|—|よ yo|
|**R**|ら ra|り ri|る ru|れ re|ろ ro|
|**W**|わ wa|—|—|—|を wo/o|
|**N**|ん n|||||

### ⚠️ Special pronunciations

- し → **shi**
- ち → **chi**
- つ → **tsu**
- ふ → **fu**
- らりるれろ → Japanese **r** sound, between English `r/l`

### Important particle readings

- は → normally **ha**, but particle = **wa**
- へ → normally **he**, but particle = **e**
- を → usually pronounced **o**

# 4. 🟦 Katakana

You need Katakana for N5/N4 because Japanese uses it for:

- foreign words
- foreign names
- countries
- companies
- food
- technology
- emphasis

Examples:

- コンピューター → konpyuutaa → computer
- テレビ → terebi → television
- インド → Indo → India
- コーヒー → koohii → coffee

> [!tip]  
> **Hiragana = Japanese/native words & grammar**
> 
> **Katakana = foreign/borrowed words**

# 18. 👉 Kore / Sore / Are / Dore

### Standalone — no noun after it

- これ → **kore** → this
- それ → **sore** → that
- あれ → **are** → that over there
- どれ → **dore** → which one

### Before a noun

- この + noun → this...
- その + noun → that...
- あの + noun → that... over there
- どの + noun → which...

### Example

これは本です。  
**Kore wa hon desu.**  
→ This is a book.

この本は私のです。  
**Kono hon wa watashi no desu.**  
→ This book is mine.

# 22. 🧱 Basic Sentence Formula

### Noun

**A は B です**

A = topic  
B = information

私は学生です。  
**Watashi wa gakusei desu.**

→ I am a student.

---

### Negative

**A は B じゃありません**

私は先生じゃありません。  
**Watashi wa sensei ja arimasen.**

→ I am not a teacher.

---

### Question

**A は B ですか**

学生ですか。  
**Gakusei desu ka?**

→ Are you a student?

# 23. 🔄 Basic Verb Forms

You MUST know these for N5/N4.

|Form|Meaning|
|---|---|
|～ます|do / will do|
|～ません|don't / won't|
|～ました|did|
|～ませんでした|didn't|

Example:

### たべます

**tabemasu**  
→ eat / will eat

### たべません

**tabemasen**  
→ don't eat / won't eat

### たべました

**tabemashita**  
→ ate

### たべませんでした

**tabemasen deshita**  
→ didn't eat

# 24. 🕐 Time Particles

### Specific time → に

7時に起きます。  
**Shichi-ji ni okimasu.**

→ I wake up **at 7**.

### Place of action → で

学校で勉強します。  
**Gakkou de benkyou shimasu.**

→ I study **at school**.

### Destination → に / へ

日本に行きます。  
**Nihon ni ikimasu.**

→ I go **to Japan**.

# 25. 🔗 Essential Connectors

5時まで  
**go-ji made**

### から〜まで

9時から5時まで  
**ku-ji kara go-ji made**

# 🧠 Your Japanese Learning Rule

For **every new grammar point**, don't just memorize the English translation.

Use this format:

```
### Grammar: ～てください

Meaning:
Please do ~

Japinglish:
"Ye kaam please kar do."

Formula:
Verb て-form + ください

Example:
ここに かいてください。
Koko ni kaite kudasai.
→ Yahan please likho.

Use case:
Teacher asks student to write.

Memory trick:
てください = "please do it"
```
