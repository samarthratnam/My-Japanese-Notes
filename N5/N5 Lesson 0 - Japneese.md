### Special pronunciations

- し → **shi**
    
- ち → **chi**
    
- つ → **tsu**
    
- ふ → **fu**
    
- らりるれろ → Japanese **r** sound, between English `r/l`
    

### Particle readings

- は → normally **ha**, particle = **wa**
    
- へ → normally **he**, particle = **e**
    
- を → usually pronounced **o**

# SECTION 2: GRAMMAR

## 1. Essential Particles

### ～は / ～が / ～を / ～に / ～で / ～の / ～と / ～も / ～から / ～まで / ～へ / ～か / ～ね / ～よ

**Meaning / Use:**  
Particles show the relationship between words in a Japanese sentence.

**Structure:**

`Noun + は + Information`

`Noun + を + Verb`

`Time + に + Verb`

`Place + で + Verb`

**Explanation:**

- は = topic
    
- が = subject
    
- を = object
    
- に = time / destination / existence
    
- で = location of action / means
    
- の = possession / relationship
    
- と = and / with
    
- も = also / too
    
- から = from
    
- まで = until / to
    
- へ = toward
    
- か = question
    
- ね = right? / agreement
    
- よ = emphasis / information
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|私は学生です。|Watashi wa gakusei desu.|I am a student.|
|ごはんをたべます。|Gohan o tabemasu.|Eat rice.|
|7時におきます。|Shichi-ji ni okimasu.|Wake up at 7.|
|学校でべんきょうします。|Gakkou de benkyou shimasu.|Study at school.|

---

## 2. Kore / Sore / Are / Dore — これ・それ・あれ・どれ

**Meaning / Use:**  
Used when the object is referred to without putting a noun after it.

**Structure:**

`これ / それ / あれ / どれ + は + Noun + です`

**Explanation:**

- これ = this
    
- それ = that
    
- あれ = that over there
    
- どれ = which one
    
- No noun comes directly after these words.
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|これは本です。|Kore wa hon desu.|This is a book.|
|これは何ですか。|Kore wa nan desu ka?|What is this?|
|それは本です。|Sore wa hon desu.|That is a book.|
|どれですか。|Dore desu ka?|Which one is it?|

---

## 3. Kono / Sono / Ano / Dono — この・その・あの・どの

**Meaning / Use:**  
Used before a noun.

**Structure:**

`この + Noun`

`その + Noun`

`どの + Noun`

**Explanation:**

- この + noun = this...
    
- その + noun = that...
    
- あの + noun = that... over there
    
- どの + noun = which...
    
- A noun comes after these words.
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|この本は私のです。|Kono hon wa watashi no desu.|This book is mine.|
|この人は学生です。|Kono hito wa gakusei desu.|This person is a student.|
|その本です。|Sono hon desu.|That book.|
|どの本ですか。|Dono hon desu ka?|Which book is it?|

---

## 4. Koko / Soko / Asoko / Doko — ここ・そこ・あそこ・どこ

**Meaning / Use:**  
Used to talk about location.

**Structure:**

`ここ / そこ / あそこ / どこ + です`

**Explanation:**

- ここ = here
    
- そこ = there
    
- あそこ = over there
    
- どこ = where
    
- こちら / そちら / あちら / どちら are also given for direction/location.
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|ここです。|Koko desu.|It is here.|
|そこです。|Soko desu.|It is there.|
|あそこです。|Asoko desu.|It is over there.|
|どこですか。|Doko desu ka?|Where is it?|

---

## 5. Basic Sentence Formula — です

### ～です

**Meaning / Use:**  
Used to state information about a noun.

**Structure:**

`A は B です`

**Explanation:**

- A = topic
    
- B = information
    
- です forms the basic noun sentence.
    
- A question uses ですか.
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|私は学生です。|Watashi wa gakusei desu.|I am a student.|
|これは本です。|Kore wa hon desu.|This is a book.|
|そうです。|Sou desu.|That's right.|
|学生ですか。|Gakusei desu ka?|Are you a student?|

### ～じゃありません

**Meaning / Use:**  
Used to make a basic noun sentence negative.

**Structure:**

`A は B じゃありません`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|私は先生じゃありません。|Watashi wa sensei ja arimasen.|I am not a teacher.|
|学生じゃありません。|Gakusei ja arimasen.|I am not a student.|
|先生じゃありません。|Sensei ja arimasen.|It is not a teacher.|
|そうじゃありません。|Sou ja arimasen.|It is not so.|

### ～ですか

**Meaning / Use:**  
Used to make a question.

**Structure:**

`A は B ですか`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|学生ですか。|Gakusei desu ka?|Are you a student?|
|何ですか。|Nan desu ka?|What is it?|
|どこですか。|Doko desu ka?|Where is it?|
|いくらですか。|Ikura desu ka?|How much is it?|

---

## 6. Basic Verb Forms

### ～ます / ～ません / ～ました / ～ませんでした

**Meaning / Use:**  
These are the basic verb forms given for N5/N4.

**Structure:**

`Verb + ます`

`Verb + ません`

`Verb + ました`

`Verb + ませんでした`

**Explanation:**

- ～ます = do / will do
    
- ～ません = don't / won't
    
- ～ました = did
    
- ～ませんでした = didn't
    

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|たべます。|Tabemasu.|Eat / will eat.|
|たべません。|Tabemasen.|Don't eat / won't eat.|
|たべました。|Tabemashita.|Ate.|
|たべませんでした。|Tabemasen deshita.|Didn't eat.|

## 7. Time Particles

### Specific time → に

**Meaning / Use:**  
Use に with a specific time.

**Structure:**

`Time + に + Verb`

**Examples:**

**Structure:**

`Place + で + Verb`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|

### Destination → に / へ

**Meaning / Use:**  
Use に or へ for a destination.

**Structure:**

`Destination + に / へ + Verb`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|

## 8. Essential Connectors

### と = and

**Meaning / Use:**  
Connects things with the meaning **and**.

**Structure:**

`A + と + B`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|

|AとB|A to B|A and B|
|私とともだち|Watashi to tomodachi|me and friend|
|父と母|Chichi to haha|father and mother|

### から = from

**Meaning / Use:**  
Shows where or when something starts.

**Structure:**

`A + から`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|9時から|Ku-ji kara|from 9 o'clock|
|日本から|Nihon kara|from Japan|
|学校から|Gakkou kara|from school|
|9時から5時まで|Ku-ji kara go-ji made|from 9 to 5|

### まで = until / to

**Meaning / Use:**  
Shows the ending point.

**Structure:**

`A + まで`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|5時まで|Go-ji made|until 5 o'clock|
|9時から5時まで|Ku-ji kara go-ji made|from 9 to 5|
|学校まで|Gakkou made|to school|
|ここまで|Koko made|to here|

### から～まで

**Meaning / Use:**  
Shows a range from a starting point to an ending point.

**Structure:**

`A + から + B + まで`

**Examples:**

|Japanese|Romaji|English|
|---|---|---|
|9時から5時まで|Ku-ji kara go-ji made|from 9 to 5|
|1時から2時まで|Ichi-ji kara ni-ji made|from 1 to 2|
|月曜日から金曜日まで|Getsuyoubi kara kinyoubi made|from Monday to Friday|
|1日から5日まで|Tsuitachi kara itsuka made|from the 1st to the 5th|
